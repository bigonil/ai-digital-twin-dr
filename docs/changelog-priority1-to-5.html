📊 #7 — Baseline Metrics Historical Range
Nuovo endpoint GET /api/metrics/range che interroga VictoriaMetrics con query_range(). Supporta metriche cpu, memory, replication_lag con lookback configurabile (1–168h). Fallback graceful: restituisce source: "unavailable" se VM non raggiungibile.
backend/api/metrics.py
💰 #9 — Cost Estimation per Recovery Strategy
Nuovo modulo cost_estimator.py: lookup table costi orari AWS on-demand (11 tipi di risorsa), moltiplicatori regionali (14 regioni), moltiplicatori per strategia di recovery. Formula: hourly × (rto/60) × strategy_mult + €46 ops. Campi hourly_cost_usd e recovery_cost_usd aggiunti a ogni nodo nel blast radius. Campo total_recovery_cost_usd nel risultato di simulazione. Visualizzato nell'header del SimulationReport.
backend/algorithms/cost_estimator.py backend/models/enhanced_graph.py backend/algorithms/cascading_failure.py
🌍 #8 — Multi-Region / Multi-AZ Latency
Nuovo modulo region_latency.py con matrice RTT inter-regione per 15 coppie AWS (es. us-east-1 ↔ eu-central-1 = 90ms, us-east-1 ↔ ap-northeast-1 = 180ms). Il BFS di cascading failure (bfs_with_latency) aggiunge overhead geografico per ogni hop cross-region o cross-AZ, rendendo la propagazione temporale realistica.
backend/algorithms/region_latency.py backend/algorithms/cascading_failure.py
